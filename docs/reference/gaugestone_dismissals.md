# gaugestone dismissals

List or remove intentional findings

## Usage

```
gaugestone dismissals
```

## Examples

```
gaugestone dismissals --json
gaugestone dismissals --remove F-012345
```

## Flags

- `--remove` Remove a stored dismissal

## Output modes

human, json

## Changes state

This command changes state and honors `--dry-run`.
