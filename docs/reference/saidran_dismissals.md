# saidran dismissals

List or remove intentional findings

## Usage

```
saidran dismissals
```

## Examples

```
saidran dismissals --json
saidran dismissals --remove F-012345
```

## Flags

- `--remove` Remove a stored dismissal

## Output modes

human, json

## Changes state

This command changes state and honors `--dry-run`.

## Related commands

- saidran dismiss
