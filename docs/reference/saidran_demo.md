# saidran demo

Try a recorded session without agent history

## Usage

```
saidran demo
```

## Examples

```
saidran demo
saidran demo --json
```

## Output

Prints text output by default.

Use `--json` for JSON output.

## Preview changes

Use `--dry-run` to preview changes without applying them.

## Related commands

- saidran check
- saidran doctor
