# saidran hook

Write a report for an agent completion event

## Usage

```
saidran hook <claude|codex> [json]
```

## Examples

```
saidran hook claude
saidran hook codex '{"thread-id":"session-id","cwd":"/repo"}'
```

## Preview changes

Use `--dry-run` to preview changes without applying them.

## Related commands

- saidran install
